# pingcli-lab

Demo-tier standalone app: the AI-DEMO2 /pingcli page as a standalone (14 allow-listed pingcli commands, SSE stream, easy-read table). Derived from AI-DEMO2 (read-only source, never imported); scaffold copied from observability-LAB.

- Run: `./scripts/run.sh` (http://localhost:7806). Test: `npm test` (server = `node --test test/*.test.js`, a glob). Preflight: `npm run doctor`. Reset: `npm run reset`. Talk track: `npm run talk-track` (a test fails on drift). Content pack: `npm run content-pack`.
- Core: `commands.js` (the allow-list, prototype-free; labels = exactly what runs minus `--config`), `mockOutput.js` (canned 1.2.0-shaped output per vertical, fake UUIDs, `.example` hosts), `realRunner.js` (spawn with `shell: false` in its own process group, private 0700 dir + 0600 config + owner.pid, minimal child env, line-buffered scrubber for secret + client id in every encoding, 15 s timeout, byte cap, session generation so nothing spawns after abort or mode switch, `dispose()` kills and awaits children before removing the dir, `sweepStale` at start-up), `pingcliCapture.js` (real 1.2.0 output, captured 2026-11-09), `config.js` (four PINGONE_* settings, region -> rootDomain, binary lookup), `readable.js` (pure, shared with the web page: `parseJsonLoose`, `extractResultRows`, `flattenResultRow`, `buildReadableView`, `tokenizeJson` with the 8000-char cap), `storyData.js` (story, banner, facts with status, `{{cast}}` tokens), `trace.js` (hops).
- Rules that bite: no free-form commands ever; the client secret is write-only (never in a response, label, error or log; tests use stub binaries in `server/test/fixtures` that echo their config and env); agents never run Real against a tenant; Mock starts no child and makes zero outbound calls; `POST /api/mode` is exactly `{ source }`; one port, 7806; cross-site GETs that spawn are 403; tests give each server its own temp root (`withServer` third arg) and never scan the shared tmpdir; only `.example`/`.invalid` hosts; never raise `JSON_HIGHLIGHT_MAX_CHARS` without a measurement.
- Honesty: facts are `observed-in-AI-DEMO2` (still UNVERIFIED here), `UNVERIFIED` or `lab`. Do not upgrade one without a real run.
- Web: `web/src/App.jsx` (shell bar, banner first, ModeToggle, ThemeToggle, presenter, Reset, five tabs), `components/PingCliPage.jsx` (the port; output only via `visible()`, never `dangerouslySetInnerHTML`), `StoryTab`, `DiagramTab` + generic `PatternDiagram`, `TraceTab` on the vendored `evidence/` screens. Vendored, do not edit: `web/src/evidence/`, `server/src/vendor/`, `scripts/lib/`, `web/src/standalone-ui.css` (pinned by `scripts/check-ui-standard.sh`). Browser check: `npm run e2e` against a running lab.
